# milk.themes
Palette button in the bar (centerEnd, next to the weather), added 2026-11-23.
- Left click: `omarchy-theme-switcher` (stock picker: previews, type to filter, Enter applies).
- Right click: `omarchy-theme-bg-switcher`.
No data, prefs or cache. Custom themes live in ~/.config/omarchy/themes/ and show up automatically.
